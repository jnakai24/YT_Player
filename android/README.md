# YT Player（Firefox / Android 版）

Windows 版 YT Player の機能を、スマホの Firefox で youtube.com を開いたときに使えるようにするユーザースクリプト（`ytplayer.user.js`）。
アプリではなく、YouTube のページの下に操作バーを足すだけなので、ログインも Premium などの特典も Firefox の YouTube のまま使える。

## バーでできること

| | |
|---|---|
| 再生リストのプルダウン | YouTube の「再生リスト」ページと同じ一覧（保存した再生リスト・後で見る・ミックスリストも）。選ぶと、前にその再生リストを聴いていた曲と位置から再生（初めてなら先頭から） |
| ⟳ | 一覧を取得し直す（ページを開くたびにも裏で取り直す） |
| ⚙ | 設定（開いたら続きから・裏で再生・診断）を出す / しまう |
| ▾ / ♪ | バーをたたむ / 開く |
| タイトル | 再生中の動画のタイトルと再生位置。動画を見ていないときは、前回の動画と止めた位置（灰色）。収まらない長さのときは 10 秒おきに左へ流れる |
| ⏮ ⏯ ⏭ | 前の動画・再生/一時停止・次の動画。ロック画面や通知の「前へ」「次へ」も曲送りになる。ページを開いた直後に押したときは、再生リストの一覧ができるのを待ってから送る |
| 🔀 | シャッフル。まだ流していない曲から順不同で選ぶ（⏭ も同じ。⏮ は直前の曲へ戻る）。長い再生リストは、ページに読み込まれている範囲から選ぶ |
| 🔁 | リピート。押すたびに オフ → 再生リスト全体 → 1 曲（🔂）。🔀 🔁 とも、曲の終わりの約 1 秒前に次の曲へ移る |
| 診断（⚙ の中） | YouTube のページに頼っている部分（ログイン・一覧の読み取り・プレイヤーの操作・曲の一覧）が動いているかを ✓ / ✗ で出す。動かなくなったときはこの画面を控える |
| オフライン優先（⚙ の中・パソコン版の表示だけ） | 保存済みの曲を、通信せずに YouTube のオフライン保存から流す。下の「オフライン保存で通信量を減らす」を参照 |
| このリストを保存（⚙ の中・パソコン版の表示だけ） | 再生中の再生リストの曲を、YouTube のオフライン保存にまとめて入れる |
| ▶（動画を見ていないとき） | 前回の動画を止めた位置から再生（位置は再生中に 5 秒ごとに記録）。⏮ ⏭ は押せない |
| 開いたら続きから | YouTube のトップ（`m.youtube.com/`）を開くと、前回の動画の止めた位置から流れる（既定はオン） |
| 裏で再生 | オンにすると、画面を消したり別のアプリに切り替えたりしても再生が続く。オフのときは YouTube 任せ（Firefox では止まらないことも多い）。既定はオフ |

設定と一覧は、その端末の Firefox の youtube.com に保存される（Windows 版とは共有しない）。

## オフライン保存で通信量を減らす（YouTube Premium）

YouTube のオフライン保存は、スマホのブラウザでは**パソコン版の表示（www.youtube.com）にしかない**。
Firefox のメニューで「デスクトップ サイト」をオンにして www.youtube.com を開くと使える。バーは同じものが大きめに出る。

1. 再生リストを選んで流す（このときは通信して再生される。数秒でスクリプトが曲順を覚える）。
2. ⚙ →「このリストを保存」。一覧の各曲の「オフライン」をスクリプトが順に押していく。終わるまでページを開いたままにする。
3. ⚙ →「オフライン優先」をオンにする。その曲のまま、保存分で流す側（`list=PPSV`）へ開き直す。
   以後は、再生リストを選んだときも「続きから」も、保存分の側で開く。

- 曲の順番は元の再生リストの順。🔀 🔁 もそのまま効く。保存していない曲は飛ばす。バーに「保存済み 40 / 56」と出る。
- 減るのは曲のデータの通信だけ。ページを開く通信は要るので、**圏外や機内モードの状態から聴き始めることはできない**。
- 保存先は Firefox の中（YouTube の仕組みのまま）。端末の空きが足りないと Firefox が消すことがある。約 30 日オンラインにならないと再生できなくなる。
- 再生リストに曲を足したら、一度「オフライン優先」をオフにして流す（曲順を覚え直す）→「このリストを保存」。

## 開いたら続きから

- トップページを開いたときだけ前回の動画に飛ぶ。動画や再生リストの URL を開いたときは、そのページのまま。
- 1 つのタブで 1 回だけ。続きが流れたあとに YouTube のロゴでトップに戻っても、もう飛ばない。
- Firefox が前回のタブ（前回の動画のページ）をそのまま開き直したときは、前回の位置まで進める。
- 再生位置は、再生中に 5 秒ごとに記録する。
- **アプリのように 1 タップで開く**：Firefox で `m.youtube.com` を開き、メニュー →「ホーム画面に追加」（または「ショートカットを追加」）。
  ホーム画面のアイコンを押すと、前回の続きが流れる。
- スマホ版の YouTube は、自動再生を許可していても開いただけでは再生を始めない。
  そこで、スクリプトが開いたページ（開いたら続きから・動画を見ていないときの ▶・再生リストを選んだとき）では、スクリプトが再生を始める。
  前回の位置へは、再生が始まってからスクリプトが進める（Firefox では URL の位置指定 `t=` が効く前に再生が始まり、先頭から流れることがあるため）。広告の間は待つ。
  再生が始まったあとに一時停止したら、それ以上は再生し直さない。
- **それでも止まっている**：Firefox が音の出る自動再生を止めている。Firefox の設定 → サイトの設定 → 自動再生 →「音声と動画を許可」。

## 入れ方（スマホ）

1. Google Play で **Firefox** を入れる（既定のブラウザにする必要はない）。
2. Firefox で `https://m.youtube.com/` を開き、Google アカウントでログインする。
3. Firefox のメニュー →「拡張機能」→ **Violentmonkey** を追加する。
4. スクリプトを入れる。どちらかで：
   - **URL から**：Firefox で次の URL を開くと Violentmonkey のインストール画面が出るので「インストール」。
     `https://raw.githubusercontent.com/jnakai24/YT_Player/main/android/ytplayer.user.js`
     （GitHub のリポジトリが公開されている場合。非公開なら下の方法で）
   - **貼り付けて**：Violentmonkey のダッシュボード →「＋」→ 新しいスクリプトの中身を全部消し、`ytplayer.user.js` の中身を貼り付けて保存。
5. YouTube を開き直すと、画面の下にバーが出る。

## 裏で再生について

- YouTube は、ページが見えなくなると Premium 以外の再生を止める。「裏で再生」はページがずっと見えていることにして、これを止めさせない。
  **Premium の機能を回避する使い方で、YouTube の利用規約に触れ得る**ので、自分の判断でオンにする。
- 長時間でも止まりにくくするには、Android の設定 → アプリ → Firefox →「電池」で制限なし（最適化しない）にする。
- 切り替えは、ページを開いた時点から効く。オンにしても止まるときは、ページを開き直す。
- **止めるとき**は、通知またはロック画面の一時停止を押す。Firefox を最近のアプリ一覧から消しても、再生中の Firefox は通知を出したまま動き続け、
  ページには何も届かない（0.9 で確認）。そのため「Firefox を閉じたら止める」はスクリプトからはできない。
  Firefox ごと終わらせたいときは、Firefox の設定 →「終了時に閲覧データを削除」をオンにするとメニューに「終了」が出る
  （消すデータの種類で Cookie とサイトデータは必ず外す。外さないとログインと YT Player の設定が消える）。

## うまく動かないとき

- ⚙ を押した行の右端に `v0.12 · page` のように、版とスクリプトが動いている場所が出る。
  - `page`：ページの中で動いている（普通の状態）。
  - `content`：Violentmonkey がページと切り離した場所で動かしている（Firefox でサイトの守りが固いとき）。0.3 からはこちらでも操作できるようにしてある。
- ⚙ を押すと、その下に「記録」が出る。Firefox から届いた知らせ（見える / 見えない、フォーカス、pagehide など、描画の停止 / 再開）を、
  そのときの再生状態と一緒に 12 件まで残す（新しいものが下）。
  記録で分かったこと：Firefox は再生中のページを、裏に回しても「見えている」扱いのままにする（「見えなくなった」が来ない）。
  「フォーカスが外れた」「描画が止まった」は、裏に回す・画面を消す・Firefox を一覧から消す、のどれでも同じように来るので見分けられない。
  pagehide は Firefox を一覧から消しても来なかった（タブの操作などで来ることがあり、来てもページは動き続ける）。
- 版が古いまま：Violentmonkey のダッシュボードで「更新を確認」、または入れたときの URL をもう一度開いて「インストール」。

## 壊れたとき

YouTube のページの作りに頼っているので、YouTube 側の変更で動かなくなることがある（Windows 版と同じ。ルートの CLAUDE.md を参照）。

- 一覧が「読めませんでした」になる：スクリプト先頭の `WEB_CLIENT_VERSION` が古すぎる可能性がある。
  パソコンの youtube.com で開発者ツールのコンソールに `ytcfg.get('INNERTUBE_CLIENT_VERSION')` と入れた値に書き換える。
- 直したら `@version` と `VERSION` を上げる（Violentmonkey が更新として扱う）。

## 仕組み（メモ）

- 一覧は YouTube 自身が使っている内部 API `/youtubei/v1/browse`（`browseId: FEplaylist_aggregation`）に、ログイン中の Cookie と
  `SAPISIDHASH` の Authorization ヘッダーを付けて問い合わせている。スマホ版の名乗り（`MWEB`）だと中身が空なので、パソコン版（`WEB`）で問い合わせる。
  結果の `lockupViewModel` の読み方は Windows 版の `PAGE_PLAYLISTS_JS` と同じ（2026-11-10 に両方の結果が一致することを確認）。
- プレイヤー操作は Windows 版と同じ `#movie_player` のメソッド。m.youtube.com にも同じものがある。
  ただし m.youtube.com ではプレイヤーが再生リストを持たない（`getPlaylist()` が空で `nextVideo()` が空振りする）ので、
  前 / 次はページの再生リストの一覧（`ytm-playlist-panel-video-renderer`）から今の動画の前後の項目を探してクリックする。
- Violentmonkey がコンテンツスクリプトとして動かしたときは、ページ側のメソッドが見えないので `wrappedJSObject` を通して触り、
  ページに渡す関数は `exportFunction` で渡す（`pageObj()` / `pageFn()`）。
- 「裏で再生」は `document.hidden` / `visibilityState` を上書きし、`visibilitychange` を止めている。ページより先に仕込むため `@run-at document-start`。
